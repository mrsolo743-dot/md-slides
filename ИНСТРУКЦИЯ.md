# Инструкция: проверка и загрузка на GitHub

## 1. Проверка локально

Нужен Python 3.9 или новее. Распакуйте архив и перейдите в папку:

```bash
cd md-slides
```

### 1.1. Запуск без установки

```bash
python -m md_slides build examples/demo.md
```

Откройте `examples/demo.html` в браузере и проверьте:

- `→` / `←` листают слайды, на 3-м слайде пункты появляются по одному;
- `P` включает режим докладчика (заметки, таймер, следующий слайд);
- `O` открывает обзор, клик по миниатюре переходит к слайду;
- `G` → введите `5` или `табл` → `Enter`;
- `T` переключает темы, `?` показывает подсказку;
- `Ctrl+P` показывает предпросмотр печати: каждый слайд на своей странице.

### 1.2. Живой предпросмотр

```bash
python -m md_slides serve examples/demo.md --open
```

Измените что-нибудь в `examples/demo.md` и сохраните: страница обновится сама. Остановка: `Ctrl+C`.

### 1.3. Установка как команды

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install .
md-slides --version
md-slides init my.md && md-slides build my.md --theme sepia
```

### 1.4. Тесты

```bash
pip install pytest
python -m pytest -q
```

Ожидаемо: `101 passed`. Если Playwright не установлен, 9 браузерных тестов будут пропущены (`92 passed, 9 skipped`). Это нормально. Чтобы их включить:

```bash
pip install playwright
python -m playwright install chromium
python -m pytest -q
```

Перед коммитом удалите временные файлы, если они появились: `.venv/`, `build/`, `*.egg-info/`. Они уже перечислены в `.gitignore`, так что git их не возьмёт.

## 2. Загрузка на GitHub

1. Откройте https://github.com/new
2. **Repository name:** `md-slides`
3. **Description:** `Автономные HTML-презентации из Markdown: подсветка кода, режим докладчика, темы, живой предпросмотр. Без зависимостей.`
4. Public. **Не** ставьте галочки README, .gitignore и License: они уже есть в проекте.
5. Нажмите **Create repository**.

Затем в папке проекта выполните:

```bash
git init
git add .
git commit -m "md-slides: генератор HTML-презентаций из Markdown"
git branch -M main
git remote add origin https://github.com/mrsolo743-dot/md-slides.git
git push -u origin main
```
