# md-slides

Презентации из **Markdown** в один HTML-файл

Нажмите `?`, чтобы увидеть горячие клавиши

Note: Это заметка докладчика. Нажмите **P**, чтобы открыть режим докладчика с таймером и следующим слайдом.

---

## Зачем это нужно

- Пишете слайды в любимом редакторе
- Храните их в git рядом с кодом
- Получаете **один файл**, который работает офлайн
- Никаких зависимостей: только Python 3.9+

> Хорошая презентация — это текст, а не набор картинок.

## Пошаговое появление

Пункты списка появляются по одному:

- Сначала идея
- Потом реализация
- И наконец ~~баги~~ тесты

Note: Директива `<!-- fragments -->` включает пошаговое появление пунктов.

## Код с подсветкой

```python
from pathlib import Path

def build(source: Path) -> str:
    """Собирает презентацию."""
    deck = parse_deck(source.read_text())
    return render(deck, theme="dark")  # 4 темы на выбор
```

```bash
md-slides build talk.md --theme light --embed-images
```

## Таблицы

| Тема       | Фон      | Шрифт        |
|:-----------|:--------:|-------------:|
| `light`    | светлый  | без засечек  |
| `dark`     | тёмный   | без засечек  |
| `terminal` | чёрный   | моноширинный |
| `sepia`    | бежевый  | с засечками  |

Переключение темы прямо во время показа: клавиша `T`.
